# Mood Visualizer 🎨

A simple web application that turns your text into animated emoji patterns based on your mood!

## Project Idea 💡

The Mood Visualizer is a creative tool that analyzes what you type and displays animated emoji patterns that match your emotions. When you type "I'm happy", the screen fills with smiling emojis that wave and dance. Type "I'm sad" and watch as sad emojis slowly move across the screen.

It's a fun way to visualize emotions through technology - turning feelings into living, breathing art!

## Features ✨

- **Real-time Mood Detection** - Automatically detects your mood as you type
- **4 Different Moods** - Happy, Sad, Angry, and Calm
- **Animated Emoji Patterns** - Each mood has unique emojis that animate differently
- **Wave Animation** - Emojis move in smooth wave patterns
- **Color-coded Moods** - Each mood has its own color scheme
- **Simple Interface** - Just type and watch the magic happen!

## How It Works 🔧

1. Type any text in the input box
2. The app scans your text for mood keywords
3. Detects your mood (happy, sad, angry, or calm)
4. Displays animated emoji patterns matching your mood
5. Each mood has different:
   - Emojis (😊 for happy, 😢 for sad, etc.)
   - Animation speed (happy is fast, sad is slow)
   - Colors (gold for happy, gray for sad, etc.)

## Mood Keywords 📝

- **Happy**: happy, joy, love, great, good, nice
- **Sad**: sad, hurt, pain, cry, bad
- **Angry**: angry, mad, hate, annoyed
- **Calm**: calm, peace, quiet, chill

## Technologies Used 💻

- **HTML5** - Structure of the web page
- **CSS3** - Styling and layout
  - Gradient backgrounds
  - Flexbox for centering
  - Border radius for rounded corners
- **JavaScript** - Animation and logic
  - DOM manipulation
  - Event listeners
  - Math.sin() for wave patterns
  - requestAnimationFrame for smooth animation

## How to Run 🚀

1. Download both files (`emotion_synthesizer.html` and `style.css`)
2. Make sure both files are in the same folder
3. Double-click `emotion_synthesizer.html` to open in your browser
4. Start typing and watch your mood come alive!
